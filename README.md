## 🎯 About the Event

AWS Community Day CEE is a groundbreaking one-day event organized **by the community, for the community**. This inaugural regional conference unites AWS communities from Austria, Croatia, Greece, Hungary, Moldova, Poland, Romania, Slovakia, Slovenia, and Ukraine in the heart of Budapest.

### 📍 Event Details

- **📅 Date**: Thursday, September 17, 2026
- **🕘 Time**: 9:00 AM - 5:00 PM (8 hours)
- **📍 Venue**: Kristály Színtér, Margitsziget, Budapest, Hungary
- **🎫 Registration**: [Eventbrite](https://www.eventbrite.com/e/aws-community-day-cee-2026-tickets-1989814613072)
- **🌐 Website**: [awscommunity.eu](https://awscommunity.eu)
- **👥 Audience**: Developers, Cloud Architects, AWS enthusiasts
- **💰 Tickets**: Starting from €25 (3 ticket tiers available)

## 🎪 Event Highlights

- **🎤 Technical Sessions** across 3 stages
- **🛠️ Hands-on Workshops** to enhance your skills  
- **🎯 Main Stage Keynotes** by AWS leaders and industry experts

- **👻 Kiro Haunted Island** - AI programming competition
